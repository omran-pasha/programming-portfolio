# Age Calculator

## Program Overview
An age conversion program that calculates how long a person has lived in different time units.

## Purpose
To convert a user's age in years into days, weeks, months, minutes, and seconds.

## Inputs
- Age in years (integer)

## Outputs
- Days lived
- Weeks lived
- Months lived
- Minutes lived
- Seconds lived

## Features
- Accurate time conversions
- Simple and clear user interaction
- Well-formatted output for readability

## Skills Demonstrated
- Arithmetic operations and conversions
- User input handling
- Output formatting
- Basic Python programming principles
